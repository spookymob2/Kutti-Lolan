Lolan SMP website
=================
index.html  - page structure
style.css   - Minecraft theme and layout
script.js   - pages, live status, reviews, admin login, cursor
assets/images/ - put your logo and images here

Keep all files in the same folder and open index.html.

Works anywhere: theme, cursor, server name and IPs, live server status.
Works only on claude.ai (published link): saved content, reviews, admin saving.
On your own hosting those pages are empty until you connect your own backend.

Admin login: username admin / password admin (set at the top of script.js).
This is NOT secure: anyone can read the password in the code.
Discord login is not included (needs a backend).
