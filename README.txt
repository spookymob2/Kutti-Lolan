Lolan SMP website
=================
index.html  - page structure
style.css   - Minecraft theme and layout
script.js   - pages, live status, reviews, admin panel, cursor

Keep all three files in the same folder and open index.html.

Works anywhere: theme, cursor, server name and IPs, live server status.
Works only on claude.ai (published link): admin panel, reviews and saved content.
On your own hosting those pages are empty until you connect your own backend.
Not included: admin/admin login and Discord login (these need a backend).
